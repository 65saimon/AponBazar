# আপন বাজার (Apon Bazar) - Website

## কিভাবে চালাবেন / How to Run

1. ZIP ফাইলটি Extract করুন
2. `index.html` ফাইলটি যেকোনো ব্রাউজারে খুলুন (Chrome, Firefox, Edge)
3. ব্যস! ওয়েবসাইট চলবে।

## ফোল্ডার স্ট্রাকচার
```
apon-bazar/
├── index.html        ← মূল পেজ
├── css/
│   └── style.css     ← সব CSS স্টাইল
├── js/
│   └── main.js       ← JavaScript
└── README.md
```
